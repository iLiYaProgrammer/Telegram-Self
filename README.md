---

⚠️ سلب مسئولیت

این پروژه فقط برای اهداف آموزشی طراحی شده است. استفاده از سلف‌بات‌ها خلاف قوانین تلگرام است و ممکن است منجر به مسدود شدن اکانت شما شود. مسئولیت هرگونه استفاده نادرست بر عهده خود کاربر است.

---

✨ امکانات (بیش از ۳۰ قابلیت)

· 🎛 پنل مدیریت دکمه‌ای (بدون نیاز به حفظ کردن دستورات)
· ⏰ ساعت پروفایل (تغییر خودکار نام خانوادگی به ساعت با فونت‌های مختلف)
· ⚔️ سیستم دشمن (پاسخ خودکار با لیست فحش‌ها)
· 🤫 سایلنت (حذف خودکار پیام‌های کاربران مشخص)
· 👥 دوست دشمن (اسپم هوشمند با تعداد محدود)
· 💬 منشی هوشمند (پاسخ خودکار به پیام‌های خصوصی)
· 🔒 قفل مدیا (جلوگیری از دریافت عکس، ویدیو، ویس و...)
· 🚪 عضویت اجباری (اجبار کاربران به عضو شدن در کانال)
· 🌍 مترجم ۴۰+ زبانه (ریپلای کن و ترجمه بگیر)
· 📥 دانلودر یوتیوب و سرچ آهنگ
· 💾 ذخیره‌کننده پیام‌های حذف شده/ویرایش شده و مدیای زمان‌دار
· 🎭 حالت‌های متن (بولد، ایتالیک، اسپویلر و...) + افکت تایپ (Action)
· 📸 اسکرین‌شات از چت + 🎙 تبدیل متن به ویس
· 💬 کامنت اول در کانال‌ها + 😂 ریکشن خودکار
· 🚀 و ده‌ها قابلیت دیگر...

---

🛠 پیش‌نیازها

· Python 3.8 یا بالاتر
· یک اکانت تلگرام (برای منیجر)
· یک ربات تلگرام (از BotFather)
· API_ID و API_HASH (از my.telegram.org)

---

🚀 نصب و راه‌اندازی

۱. پروژه را کلون کنید:

```bash
git clone https://github.com/iLiYaProgrammer/Telegram-Self.git
cd Telegram-Self
```

۲. کتابخانه‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

۳. اطلاعات خود را در ابتدای فایل self.py جایگزین کنید:

```python
api_id = 12345678            # API_ID شما
api_hash = "you_api_hash"    # API_HASH شما
BOT_TOKEN = "You_bot_token"  # توکن ربات شما
BOT_USERNAME = "YourBotUsername"
```

۴. فایل را اجرا کنید:

```bash
python self.py
```

در اولین اجرا، اکانت‌ها لاگین شده و سشن‌ها در پوشه sessions ذخیره می‌شوند.

---

📜 نحوه استفاده

· در چت با خودتان (Saved Messages) کلمه پنل را بفرستید.
· سپس روی پیام ظاهر شده کلیک کنید تا پنل مدیریت باز شود.
· از داخل پنل، به تمام دستورات و تنظیمات دسترسی خواهید داشت.

---

📂 ساختار پروژه

```text
Telegram-Self/
├── self.py           # فایل اصلی
├── requirements.txt  # لیست کتابخانه‌ها
├── data2.json        # دیتابیس تنظیمات (خودکار ساخته می‌شود)
├── sessions/         # ذخیره سشن‌های اکانت‌ها
├── downloads/        # فایل‌های دانلود شده
└── saved_media/      # مدیاهای ذخیره شده
```
